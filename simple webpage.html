Welcome to My Webpage

This is a simple paragraph of text to demonstrate the structure of a basic webpage using HTML.
HTML stands for HyperText Markup Language.


🔍 Explanation:

DOCTYPE html: — Declares the document type as HTML5.
html lang="en": — The root of the HTML document; lang="en" defines the language as English.
head: — Contains metadata, including the title and character settings.
title: — Sets the browser tab title.
body: — The visible content of the webpage:
h1 Tag: — A top-level heading.
p Tag: — A paragraph of descriptive text.
img Tag: — Displays an image with a source URL and alt text.
